# 🧠 Brain Brawl

**Brain Brawl** is a dynamic and responsive quiz app that generates AI-powered questions on the fly using the **Gemini API**. Whether you're practicing for fun or competing with friends, Brain Brawl delivers questions in real-time for a smooth and engaging experience.

> Built with **Vite + React** and powered by a **Node.js + Express** backend.

---

## 🚀 Features

- 🎯 **AI-Powered Questions**  
  Generate intelligent, topic-based questions instantly using Gemini.
  
- 🧩 **Customization Options**  
  Select difficulty level, question type, and number of questions.

- 🔁 **Real-Time Question Streaming**  
  No reloads, no delays – questions appear as they are generated.

- 📱 **Responsive Design**  
  Seamlessly accessible on mobile, tablet, and desktop.

- 👤 **User Profiles** 
  Track your progress, favorite topics, and history.

- 🏆 **Leaderboard System**   
  See how you rank among other Brain Brawlers.

- 🌐 **Live Deployment**  
  Hosted with lightning-fast performance on **Vercel** and **Railway**.

---

## 🔧 Tech Stack

| Frontend      | Backend        | Deployment     |
|---------------|----------------|----------------|
| React (Vite)  | Express (Node) | Vercel (client)|
| Tailwind CSS  | Gemini API     | Railway (server)|
